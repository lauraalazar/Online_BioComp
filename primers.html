Primers (cebadores)#

La reacción en cadena de la polimerasa (PCR) es una técnica de laboratorio muy común que se utiliza para obtener millones copias de una región específica del ADN. El objetivo principal de la PCR es amplificar dicha región generando suficiente cantidad de ADN para poder analizarlo o usarlo en otros experimentos. Por ejemplo, el ADN amplificado puede enviarse a secuenciar, observarse mediante electroforesis en gel o clonarse en un plásmido para investigaciones adicionales.

https://www.khanacademy.org/science/ap-biology/gene-expression-and-regulation/biotechnology/a/polymerase-chain-reaction-pcr

Qué se requiere para realizar una PCR?#

  • Nucleótidos

  • Taq polimerasa

  • Primers: son las secuencias cortas (aprox 20n) que pueden iniciar la replicación de DNA y le dan especificidad a la PCR

https://www.khanacademy.org/

Ciclos de la PCR#

    1. Desnaturalización (96 °C): Se calienta fuertemente la reacción para separar, o desnaturalizar, las hebras de ADN. Esto genera plantillas de cadena sencilla para el siguiente paso.

    1. Alineamiento (55–65 °C): Se enfría la reacción para que los cebadores (primers) puedan unirse a sus secuencias complementarias en el ADN monocatenario.

    1. Extensión (72 °C): Se aumenta la temperatura para que la Taq polimerasa extienda los cebadores, sintetizando nuevas hebras de ADN.

Parámetros para diseñar primers#

1. Especificidad#

  • forward primer: primeros nucleótidos gen 5’-3’

  • reverse primer: complemento reverso 5’-3’

2. Longitud#

  • 18-24 bases es óptimo

  • si es muy corto pueden producir amplificaciones poco específicas

  • si es muy largo pueden producir hibridación lenta y se pierde la exponencialidad de la reacción

3. Temperatura de unión#

  • La temperatura de melting (Tm) es aquella donde la mitad de los primers se disocian del DNA. Los dos (forward y reverse) deben tener similar Tm. Un rango de 52-58°C produce los mejores resultados.

4. Contenido de GC#

  • Un contenido alto de GC mejora la estabilidad entre los primers y la secuencia moldeEl contenido ideal de GC de un primer es 40-60%.

5. Estructuras secundarias#

  • Dependiendo de la secuencia del primer, se pueden formar estructuras secundarias, lo que conlleva a que se hibridice entre sí en vez de unirse al DNA molde

https://microbeonline.com/designing-pcr-primers-design-consideration-and-uses/

PrimerBlast: estudio de caso gen trasnportador de Cadmio en Cacao (por Felipe Arango)#

Vamos a utilizar una herramienta para diseñar primers teniendo en cuenta los parámetros especificados anteriormente. Para ilustrar el proceso, vamos a enfocarnos en la identificación de genes asociados al transporte de Cadmio en Theobroma cacao L. (leer documento anexo preparado por Felipe Arango).

  1. Vamos a descargar uno de los genes pertenecientes a la familia de las NRAMPs (Natural Resistance-Associated Macrophage Proteins), NRAMP5, el cual se considera asociado a la entrada de Cadmio desde la rizosfera. Entrar a https://www.ncbi.nlm.nih.gov/ y escoger la base de datos “Gene”. Escribir términos NRAMP5 Theobroma Cacao L. Revise la información sobre el gen, y piense donde cree que encontraría la secuencia para diseñar los primers? Descargue la secuencia fasta. Este paso también se puede realizar desde el siguiente script (note que en este caso el gen lo buscaremos por sus coordenadas en el cromosoma, en vez de su anotación).

#!/usr/local/bin/

# Script por Laura Salazar Jaramillo
# Busca la secuencia de un gen


from Bio import Entrez
from Bio import SeqIO

Entrez.email = "lsalazarj@eafit.edu.co"

with Entrez.efetch(
    db="nucleotide", rettype="fasta", retmode="text", id="NC_030857.1",  strand=2, 
                       seq_start=6830167, #coordenada de inicio
                       seq_stop=6825279) as handle: #coordenada final
    seq_record = SeqIO.read(handle, "fasta")

print(seq_record)
SeqIO.write(seq_record, "/home/lsalazarj/bicomp2025-1/primers/NRAMP5_ref.fa", "fasta")

  1. Entre a la aplicación PrimerBlast https://www.ncbi.nlm.nih.gov/tools/primer-blast/ y copia-pega la secuencia descargada.

  2. Los siguientes parámetros se pueden modificar según el criterio:

    • a. PCR product length: productos cortos pueden producir múltiples targets, productos largos una PCR ineficiente (para qPCR se recomienda entre 100-500)

    • b. Temperatura melting (Tm) (minimum, optimal, maximum, difference between the set). Cerca de 60ºC es una temperatura alta que permite especificidad del primer (por qué cree?) y así evitar false priming. La Tm del par debe estar suficientemente cerca para que el alineamient (annealing) sea lo más sincronizado posible.

    • c. Para PCR normal el primer puede estar en cualquier parte del gen, incluyendo intrones, exones, regiones no-codificantes. Para qPCR debe utilizarse la opción “Primer must span an exon-exon junction” para seleccionar mRNA

    • d. Refseq proporciona secuencias de ocurrencias naturales occurring sequences. Descarta secuencias de plásmidos o constructos de vectores

    • e. Selecciona el organismo para BLAST

  1. Escoja un par de primers y anote los parámetros que proporciona el programa

Variante de un gen#

Vamos a estudiar una secuencias de genes codificantes para transportadores NRAMP5 de una variedad colombiana (CCN51) con el genoma de referencia disponible en NCBI (NCBI RefSeq assembly: GCF_000208745.1), para identificar similitudes o diferencias, localizar los genes en los cromosomas, y diseñar primers para PCR convencional.

  1. Vamos a descargar la secuencia https://raw.githubusercontent.com/Pipe-95/TallerBiologiaComputacional/refs/heads/main/NRAMP5.fa

  2. Ahora descargamos los cromosomas dada la lista de ID de los cromosomas

import Bio
from Bio import Entrez, SeqIO

Entrez.email = "farangoh@eafit.edu.co" #modifique el email con el suyo

# Lista de IDs de los cromosomas a descargar
cromosomas_ids = ["NC_030850.1", "NC_030851.1", "NC_030852.1", "NC_030853.1", "NC_030854.1", "NC_030855.1", "NC_030856.1", "NC_030857.1", "NC_030858.1", "NC_030859.1"]

# Ruta del archivo final fusionado
ruta_salida = "genoma_cacao.txt"

# Lista para guardar las secuencias
secuencias = []

# Descargar y almacenar cada secuencia
for idx, crom_id in enumerate(cromosomas_ids, start=1): 
    try:
        with Entrez.efetch(db="nucleotide", rettype="fasta", retmode="text", id=crom_id) as handle:
            seq_record = SeqIO.read(handle, "fasta")
            secuencias.append(seq_record) # append: añade un item a la lista en vez de sobreescribir
            print(f"Cromosoma {idx} guardado exitosamente: ID {seq_record.id}, longitud {len(seq_record.seq)} pb")
    except Exception as e:
        print(f"Error al descargar cromosoma {idx} (ID {crom_id}): {e}")


# Escribir todas las secuencias en un solo archivo FASTA
try:
    SeqIO.write(secuencias, ruta_salida, "fasta")
    print(f"\nTodas las secuencias fueron fusionadas en: {ruta_salida}")
except Exception as e:
    print(f"Error al escribir las secuencias")

  1. Generar la base de datos para BLAST utilizand mkblastdb (dentro de un script slurm)

##### ENVIRONMENT CREATION #####
module load blast/2.13.0_gcc-11.2.0

##### JOB COMMANDS ####
makeblastdb -in genoma_cacao.txt -title Base_datos_T.cacao -dbtype nucl -out cacao_database -parse_seqids

  1. Ahora realizamos Blast de la secuencia query (NRAMP5) contra la base de datos cacao_database

##### ENVIRONMENT CREATION #####
module load blast/2.13.0_gcc-11.2.0

blastn -query NRAMP5.fa -db cacao_database -out NRAMP5_blastn_table.txt -evalue 1e-30 -outfmt 6

Análisis de resultados de BLAST

  • ¿Cuántos alineamientos (matches) encontró para cada una de las secuencias?

  • En caso de haber más de uno: ¿Se encuentran todos en el mismo cromosoma?

  • Si están en el mismo cromosoma, ¿pertenecen al mismo locus o están en regiones distintas?

  • ¿Qué tan específico es el primer?
